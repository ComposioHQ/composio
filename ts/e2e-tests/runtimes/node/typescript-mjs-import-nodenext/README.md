# TypeScript .mjs Import Resolution Test

Verifies that Composio-generated TypeScript files compile correctly with `moduleResolution: "nodenext"`.

## Background

When `composio generate ts --output-dir ./types` runs without `--transpiled`:

- Only `.ts` files are generated
- These files contain `import ... from "./foo.mjs"` statements
- With `moduleResolution: "node16"` or `"nodenext"`, TypeScript resolves:
  - `.js` imports → `.ts` files ✅
  - `.mjs` imports → `.mts` files only (not `.ts`) ❌

This causes `TS2307: Cannot find module './foo.mjs'` errors.

## What It Tests

| Test                   | Description                                                    |
| ---------------------- | -------------------------------------------------------------- |
| Fixture files          | Uses committed Composio-generated TypeScript sources           |
| File existence         | Verifies generated .ts files exist                             |
| TypeScript compilation | Runs `tsc --noEmit` to check import resolution                 |

## Fixture

```
fixtures/
├── fixture-generated/
│   ├── codeinterpreter.ts
│   └── index.ts
├── index.mjs       # Test runner script that validates and compiles TypeScript
└── tsconfig.json   # TypeScript config with moduleResolution: "nodenext"
```

The fixture script:

1. Reads committed TypeScript fixture files generated by Composio CLI
2. Verifies generated `.ts` files exist
3. Runs `npx tsc --noEmit` to check TypeScript compilation
4. Fails if TS2307 errors occur (indicating `.mjs` import bug)

The live `composio generate ts` command is already covered by CLI unit tests in
`ts/packages/cli/test/src/commands/ts/ts.generate.cmd.test.ts`. This E2E suite
is intentionally deterministic and focuses only on NodeNext import resolution.

**tsconfig.json:**

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "nodenext",
    "strict": true,
    "noEmit": true
  },
  "include": ["generated/**/*.ts"]
}
```

## Isolation Tool

**Docker** with the Node.js version selected by the Node E2E matrix.

## Running

```bash
pnpm test:e2e
```

## Expected Behavior

- **If bug exists (importExtension: 'mjs')**: TypeScript compilation fails with TS2307
- **If fixed (importExtension: 'js')**: All tests pass
