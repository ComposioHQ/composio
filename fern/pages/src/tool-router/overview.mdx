Tool Router is a unified interface that lets an agent **search**, **plan**, **authenticate**, and **execute** actions across thousands of Composio tools.

<Info>
**What Tool Router is NOT:** Tool Router is not a separate product or service you install — it's the engine behind every `composio.create()` call. If you've used the Composio SDK to create a session, you've already used Tool Router.
</Info>

Consider an agent that works across Gmail, Notion, Slack, Google Drive, and hundreds of other apps. The challenges:

- **Search**: Identifying the right tool for the task
- **Context Management**: Managing context for complex queries with large responses
- **Authentication**: Handling authentication across all of them

Tool Router exposes a set of meta-tools that handle all this complexity including search to discover the right tools, and a workbench to process results without flooding context.

This is what powers complex agentic products like [Rube](https://rube.app).

## What Tool Router does

When an agent needs to use a tool, Tool Router:

1. **Discovers relevant tools** — surfaces the right tools based on the agent's task, so the LLM doesn't get overwhelmed with 1000+ tool definitions
2. **Handles authentication** — prompts users to connect accounts when needed, or uses existing connections silently
3. **Routes execution** — sends tool calls to the right service with the right credentials
4. **Manages context** — provides tool schemas, descriptions, and metadata optimized for LLM consumption

### Meta tools

Tool Router sessions include **meta tools** — special tools that the agent uses to interact with Composio itself:

| Meta Tool | Purpose |
|-----------|---------|
| `COMPOSIO_SEARCH_TOOLS` | Find relevant tools based on a natural language query. Returns tool names, descriptions, and schemas for the top matches. |
| `COMPOSIO_MANAGE_CONNECTIONS` | Prompt users to connect accounts when a tool requires auth. Returns a Connect Link URL the user can click. |
| `COMPOSIO_EXECUTE_TOOL` | Execute a discovered tool with arguments. Handles credential injection and API routing. |

## Common patterns

| Pattern | Description | Guide |
|---------|-------------|-------|
| **Interactive chat agent** | Users chat with an agent that discovers and uses tools on the fly. Tool Router handles auth prompts in-conversation. | [Quickstart](/tool-router/quickstart) |
| **Background automation** | Collect OAuth consent upfront in your UI, then run headless agents in cron jobs or webhooks with `manageConnections: false`. | [Background Agents](/docs/background-agents) |
| **Check connection status** | Programmatically check if a user has connected a specific toolkit before running an agent. | [Managed Authentication](/docs/managed-authentication#check-if-a-user-has-connected-a-toolkit) |
| **Multi-tenant isolation** | Use one Composio project per customer for complete user and credential isolation. | [Project Isolation](/docs/project-isolation) |
