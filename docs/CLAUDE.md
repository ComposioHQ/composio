# Composio Documentation

Documentation site built with [Fumadocs](https://fumadocs.dev/).

## Quick Reference

```bash
bun install          # Install dependencies
bun run dev          # Dev server (http://localhost:3000)
bun run build        # Production build (validates TS code blocks)
bun run types:check  # Type check
bun run scripts/validate-links.ts  # Check internal links (needs bunfig.toml)
bun run generate:meta-tools        # Regenerate meta-tools from Tool Router API
```

## Git Workflow

Docs branches are based off `next` and PRs target `next` (not `master`).

## Key Rules

1. **TS code blocks are type-checked** at build time. See `.claude/context/twoslash.md`.
2. **Run `bun run build` before pushing** -- catches type errors `bun dev` misses.
3. **CSS variables**: use `var(--composio-orange)` not `var(--orange)`. Check `app/global.css`.
4. **`public/data/toolkits.json` must exist** -- errors thrown, not ignored.
5. **Meta tools**: `public/data/meta-tools.json` and `content/reference/meta-tools/` are auto-generated. `MetaToolDetailServer` reads JSON at build time -- do NOT register in `mdx-components.tsx`.
6. **Toolkit FAQ files**: plain markdown in `content/toolkits/faq/{slug}.md` (no frontmatter). Excluded from Fumadocs source via `source.config.ts` but scanned by link checker.
7. **Link checker**: validates internal links using populate keys with `(home)/` prefix. Dynamic toolkit pages checked against `public/data/toolkits.json` slugs.
8. **Glossary**: `content/docs/glossary.mdx` uses `<GlossaryTerm>` components converted to `### Term` headings for LLM output.
9. **Test on mobile** -- Fumadocs nav differs on mobile.

## API Versioning

- **v3.1** (default): `/reference/api-reference/...` -- tool endpoints default to latest toolkit version
- **v3.0**: `/reference/v3/api-reference/...` -- tool endpoints default to pinned version `00000000_00`
- Non-API pages under `content/reference/v3/` are manual copies -- update both when content changes
- API index pages and OpenAPI specs auto-generated by CI (`docs-update-data.yml`)
- SDK Reference and Meta Tools shared across versions (not duplicated)

## LLM Guardrails

Every `.md` endpoint appends invisible guardrails steering AI toward session-based patterns. Controlled via `llmGuardrails` frontmatter. See `.claude/decisions/llm-guardrails.md`.

## Conventions

- Review `docs/examples/` for correctness and clarity only, not production-readiness.
- Prefer cURL over "click" in docs -- most traffic is AI crawlers.
