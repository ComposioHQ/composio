The Vercel AI SDK provider transforms Composio tools into Vercel's [tool format](https://sdk.vercel.ai/docs/ai-sdk-core/tools-and-tool-calling) with built-in execution — no manual agentic loop needed.

<Callout type="warn">
**AI SDK 5 vs 6 have breaking API differences.** Composio supports both **AI SDK 5** (`ai@^5`) and **AI SDK 6** (`ai@^6`). The key behavioral change: V5 defaults to **single-step** tool calling (your agent calls one tool and stops), while V6 defaults to **multi-step** (the agent loops automatically). If your agent calls one tool and immediately returns without finishing, you're likely on V5 without `stopWhen` — see [key differences](#key-differences-between-ai-sdk-5-and-6) below.
</Callout>

<Callout type="info">
**Which version am I on?** Check your `package.json`: `"ai": "^5.x"` is V5, `"ai": "^6.x"` is V6. If you can import `Agent` from `"ai"`, you're on V6 — that class doesn't exist in V5. **Starting a new project?** Use AI SDK 6.
</Callout>

**Create session and run**

The Vercel provider is **agentic** — tools include an `execute` function, so the AI SDK handles tool calls automatically.

<Tabs groupId="ai-sdk-version" items={['AI SDK 6', 'AI SDK 5']} persist>
<Tab value="AI SDK 6">

AI SDK 6 introduces the `Agent` abstraction and renames `system` to `instructions`. The default `stopWhen` is `stepCountIs(20)`, so multi-step agent loops work out of the box.

```typescript
// @noErrors
import { anthropic } from "@ai-sdk/anthropic";
import { Composio } from "@composio/core";
import { VercelProvider } from "@composio/vercel";
import { Agent, generateText } from "ai";

const composio = new Composio({ provider: new VercelProvider() });

const session = await composio.create("user_123");
const tools = await session.tools();

// Use the Agent abstraction for reusable agent configs
const agent = new Agent({
  model: anthropic("claude-opus-4-6"),
  tools,
  instructions: "You are a helpful assistant that uses Composio tools to take action.",
});

const { text } = await generateText({
  agent,
  prompt: "Send an email to john@example.com with the subject 'Hello' and body 'Hello from Composio!'",
});

console.log(text);
```
</Tab>
<Tab value="AI SDK 5">

In AI SDK 5, use `generateText` directly with `system` and an explicit `stopWhen` (defaults to 1 step).

```typescript
import { anthropic } from "@ai-sdk/anthropic";
import { Composio } from "@composio/core";
import { VercelProvider } from "@composio/vercel";
import { generateText, stepCountIs } from "ai";

const composio = new Composio({ provider: new VercelProvider() });

const session = await composio.create("user_123");
const tools = await session.tools();

const { text } = await generateText({
  model: anthropic("claude-opus-4-6"),
  tools,
  system: "You are a helpful assistant that uses Composio tools to take action.",
  prompt: "Send an email to john@example.com with the subject 'Hello' and body 'Hello from Composio!'",
  stopWhen: stepCountIs(10), // Required in v5 for multi-step loops
});

console.log(text);
```

## Key differences between AI SDK 5 and 6

| Feature | AI SDK 5 (`ai@^5`) | AI SDK 6 (`ai@^6`) |
|---------|-------|-------|
| Agent abstraction | None — pass config inline to `generateText`/`streamText` | `new Agent({ model, tools, instructions })` |
| System prompt | `system: "..."` | `instructions: "..."` |
| Default step count | `stopWhen: stepCountIs(1)` (single step) | `stopWhen: stepCountIs(20)` (multi-step) |
| Tool calling | Manual agentic loop with `stopWhen` | Automatic via `Agent` — handles multi-step tool calls by default |
| Structured output | `generateObject` / `streamObject` | `generateText` / `streamText` with `output` option |

### What this means in practice

The biggest behavioral difference is **how tool-calling loops work**:

- **AI SDK 5** defaults to a single step — the model calls one tool and stops. To get multi-step agent behavior (model calls tool → reads result → calls another tool → ...), you must set `stopWhen: stepCountIs(N)`. Without this, your agent will try to use a Composio tool once and then return, even if the task isn't complete.

- **AI SDK 6** defaults to 20 steps via the `Agent` abstraction. The model will keep calling tools and reasoning until it considers the task done (or hits the step limit). This is the behavior most developers expect from an "agent."

<Callout type="warn">
**Common pitfall on AI SDK 5:** If your agent calls one tool and then immediately returns a text response without finishing the task, you're likely missing `stopWhen`. Add `stopWhen: stepCountIs(10)` (or higher) to enable multi-step tool calling.
</Callout>

### The `Agent` abstraction (V6 only)

In AI SDK 6, `Agent` is a reusable configuration object — think of it as a named, preconfigured agent template. This is useful when you want to define an agent once and run it multiple times:

```typescript
// @noErrors
import { Agent, generateText } from "ai";
import { anthropic } from "@ai-sdk/anthropic";

// Define the agent once
const emailAgent = new Agent({
  model: anthropic("claude-sonnet-4-6"),
  tools, // Composio tools from session.tools()
  instructions: "You help users manage their email.",
});

// Reuse it for different prompts
const { text: summary } = await generateText({
  agent: emailAgent,
  prompt: "Summarize my unread emails",
});

const { text: draft } = await generateText({
  agent: emailAgent,
  prompt: "Draft a reply to the latest email from Alice",
});
```

In AI SDK 5, you'd pass `model`, `tools`, `system`, and `stopWhen` directly to `generateText` every time — there's no equivalent reusable abstraction.

<Callout type="info">
**Which version should I use?** If you're starting a new project, use AI SDK 6. The `Agent` abstraction simplifies multi-step tool calling significantly — you no longer need to manage `stopWhen` or build your own agentic loop. If you're on an existing AI SDK 5 project, both versions work with Composio — upgrade when ready.
</Callout>

For the full migration guide, see [Vercel's AI SDK 5 to 6 migration docs](https://ai-sdk.dev/docs/migration-guides/migration-guide-6-0).
