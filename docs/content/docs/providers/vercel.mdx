The Vercel AI SDK provider transforms Composio tools into Vercel's [tool format](https://sdk.vercel.ai/docs/ai-sdk-core/tools-and-tool-calling) with built-in execution — no manual agentic loop needed.

<Callout type="info">
Composio supports both **AI SDK 5** (`ai@^5`) and **AI SDK 6** (`ai@^6`). The examples below show both versions where the API differs. If you're starting a new project, use AI SDK 6.
</Callout>

<Steps>
<Step>
**Install**

```bash
npm install @composio/core @composio/vercel ai @ai-sdk/anthropic
```
</Step>

<Step>
**Configure API Keys**

<Callout type="info">
Set `COMPOSIO_API_KEY` with your API key from [Settings](https://platform.composio.dev/?next_page=/settings) and `ANTHROPIC_API_KEY` with your [Anthropic API key](https://console.anthropic.com/settings/keys).
</Callout>

```txt title=".env"
COMPOSIO_API_KEY=xxxxxxxxx
ANTHROPIC_API_KEY=xxxxxxxxx
```
</Step>

<Step>
**Create session and run**

The Vercel provider is **agentic** — tools include an `execute` function, so the AI SDK handles tool calls automatically.

<Tabs groupId="ai-sdk-version" items={['AI SDK 6', 'AI SDK 5']} persist>
<Tab value="AI SDK 6">

AI SDK 6 introduces the `Agent` abstraction and renames `system` to `instructions`. The default `stopWhen` is `stepCountIs(20)`, so multi-step agent loops work out of the box.

```typescript
// @noErrors
import { anthropic } from "@ai-sdk/anthropic";
import { Composio } from "@composio/core";
import { VercelProvider } from "@composio/vercel";
import { Agent, generateText } from "ai";

const composio = new Composio({ provider: new VercelProvider() });

const session = await composio.create("user_123");
const tools = await session.tools();

// Use the Agent abstraction for reusable agent configs
const agent = new Agent({
  model: anthropic("claude-opus-4-6"),
  tools,
  instructions: "You are a helpful assistant that uses Composio tools to take action.",
});

const { text } = await generateText({
  agent,
  prompt: "Send an email to john@example.com with the subject 'Hello' and body 'Hello from Composio!'",
});

console.log(text);
```
</Tab>
<Tab value="AI SDK 5">

In AI SDK 5, use `generateText` directly with `system` and an explicit `stopWhen` (defaults to 1 step).

```typescript
import { anthropic } from "@ai-sdk/anthropic";
import { Composio } from "@composio/core";
import { VercelProvider } from "@composio/vercel";
import { generateText, stepCountIs } from "ai";

const composio = new Composio({ provider: new VercelProvider() });

const session = await composio.create("user_123");
const tools = await session.tools();

const { text } = await generateText({
  model: anthropic("claude-opus-4-6"),
  tools,
  system: "You are a helpful assistant that uses Composio tools to take action.",
  prompt: "Send an email to john@example.com with the subject 'Hello' and body 'Hello from Composio!'",
  stopWhen: stepCountIs(10), // Required in v5 for multi-step loops
});

console.log(text);
```
</Tab>

## Key differences between AI SDK 5 and 6

| Feature | AI SDK 5 (`ai@^5`) | AI SDK 6 (`ai@^6`) |
|---------|-------|-------|
| Agent abstraction | None — pass config inline to `generateText`/`streamText` | `new Agent({ model, tools, instructions })` |
| System prompt | `system: "..."` | `instructions: "..."` |
| Default step count | `stopWhen: stepCountIs(1)` (single step) | `stopWhen: stepCountIs(20)` (multi-step) |
| Tool calling | Manual agentic loop with `stopWhen` | Automatic via `Agent` — handles multi-step tool calls by default |
| Structured output | `generateObject` / `streamObject` | `generateText` / `streamText` with `output` option |

<Callout type="info">
**Which version should I use?** If you're starting a new project, use AI SDK 6. The `Agent` abstraction simplifies multi-step tool calling significantly — you no longer need to manage `stopWhen` or build your own agentic loop. If you're on an existing AI SDK 5 project, both versions work with Composio — upgrade when ready.
</Callout>

For the full migration guide, see [Vercel's AI SDK 5 to 6 migration docs](https://ai-sdk.dev/docs/migration-guides/migration-guide-6-0).
