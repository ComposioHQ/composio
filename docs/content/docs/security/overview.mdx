### Credential protection

Provider credentials are encrypted at rest using AES-256-GCM. Composio API keys and session keys are stored as hashes. Traffic uses TLS. Composio uses credentials during execution. ZDR controls storage of covered payloads, not processing during execution.

### Your responsibilities

You authenticate your users and decide which accounts and tools they can access. [Per-action permissions](/docs/governance/action-permissions) restrict which actions a session can run, and [Firewall](/docs/firewall) blocks tool calls or results by condition. Review those choices alongside your application's own logs and model-provider policies.
