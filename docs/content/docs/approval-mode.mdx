---
title: Approval mode
description: Ask the user before your agent runs tools that send, post or delete things on their behalf
keywords: [approval, human in the loop, elicitation, require_approval, input_required, confirmation]
---

Approval mode lets a session ask the user before certain tools run. When the agent calls one, Composio returns an elicitation for the user instead of running the tool, and runs it once it receives their answer.

<Callout type="warn" title="Experimental">
Approval mode is experimental. It needs `composio` newer than 0.27.0 or `@composio/core` newer than 0.24.0.
</Callout>

## Requiring approval

Require approval for every tool with a [tag](/docs/tool-tags):

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
session = composio.create(
    user_id="user_123",
    tags={"require_approval": ["createHint", "updateHint", "destructiveHint"]},
)
```
</Tab>
<Tab value="TypeScript">
```typescript
// @noErrors
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: 'your_api_key' });
// ---cut---
const session = await composio.create('user_123', {
  tags: { requireApproval: ['createHint', 'updateHint', 'destructiveHint'] },
});
```
</Tab>
</Tabs>

Or set it per toolkit, which overrides `tags` for that toolkit:

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
session = composio.create(
    user_id="user_123",
    tools={
        "gmail": {
            "enable": ["GMAIL_FETCH_EMAILS", "GMAIL_SEND_EMAIL"],
            "require_approval": ["GMAIL_SEND_EMAIL"],  # set even if empty
        },
    },
)
```
</Tab>
<Tab value="TypeScript">
```typescript
// @noErrors
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: 'your_api_key' });
// ---cut---
const session = await composio.create('user_123', {
  tools: {
    gmail: {
      enable: ['GMAIL_FETCH_EMAILS', 'GMAIL_SEND_EMAIL'],
      requireApproval: ['GMAIL_SEND_EMAIL'], // set even if empty
    },
  },
});
```
</Tab>
</Tabs>

Tools that need approval stay visible to the agent. In `COMPOSIO_MULTI_EXECUTE_TOOL`, each call that needs approval gets its own question.

## Asking the user

When a tool needs approval, `session.execute()` raises an error:

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
from composio.exceptions import ToolInputRequiredError

arguments = {"recipient_email": "priya@acme.com", "subject": "Q3 numbers"}

try:
    session.execute("GMAIL_SEND_EMAIL", arguments=arguments)
except ToolInputRequiredError as error:
    questions = error.input_requests
    request_state = error.request_state
```
</Tab>
<Tab value="TypeScript">
```typescript
// @noErrors
import { Composio, ComposioToolInputRequiredError, type ToolRouterInputRequest } from '@composio/core';
const composio = new Composio({ apiKey: 'your_api_key' });
const session = await composio.create('user_123');
// ---cut---
const args = { recipient_email: 'priya@acme.com', subject: 'Q3 numbers' };
let questions: Record<string, ToolRouterInputRequest> = {};
let requestState: string | undefined;

try {
  await session.execute('GMAIL_SEND_EMAIL', args);
} catch (error) {
  if (error instanceof ComposioToolInputRequiredError) {
    questions = error.inputRequests;
    requestState = error.requestState;
  }
}
```
</Tab>
</Tabs>

`input_requests` holds the questions, keyed by ID. Each one is an [MCP elicitation](https://modelcontextprotocol.io/specification/2026-07-28/client/elicitation):

```json
{
  "elicit_0f2f8872eea523ed": {
    "type": "elicitation",
    "mode": "form",
    "message": "Your agent wants to run the following tool:\n\nGMAIL_SEND_EMAIL({\"recipient_email\": \"priya@acme.com\", \"subject\": \"Q3 numbers\"})",
    "requested_schema": {
      "type": "object",
      "properties": {
        "decision": {
          "type": "string",
          "title": "Decision",
          "oneOf": [
            { "const": "approve", "title": "Approve" },
            { "const": "always_approve", "title": "Always approve" },
            { "const": "deny", "title": "Deny" }
          ]
        }
      },
      "required": ["decision"]
    }
  }
}
```

Show the user the `message` and a form built from `requested_schema`. Build the form from the schema, since the choices vary between questions.

## Sending the answer

Send the same call again with the user's answers:

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
result = session.execute(
    "GMAIL_SEND_EMAIL",
    arguments=arguments,
    input_responses={
        "elicit_0f2f8872eea523ed": {
            "action": "accept",
            "content": {"decision": "approve"},
        }
    },
    request_state=request_state,
)
```
</Tab>
<Tab value="TypeScript">
```typescript
// @noErrors
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: 'your_api_key' });
const session = await composio.create('user_123');
const args = { recipient_email: 'priya@acme.com', subject: 'Q3 numbers' };
declare const requestState: string | undefined;
// ---cut---
const result = await session.execute('GMAIL_SEND_EMAIL', args, {
  inputResponses: {
    elicit_0f2f8872eea523ed: {
      action: 'accept',
      content: { decision: 'approve' },
    },
  },
  requestState,
});
```
</Tab>
</Tabs>

When the user picks **Always approve**, their approval lasts for the rest of the session. Later calls to that tool on the same connected account run without asking again.

## End-to-end example

An agent loop with Claude that asks for approval in the terminal:

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
import json

import anthropic
from composio import Composio
from composio.exceptions import ToolInputRequiredError
from composio_anthropic import AnthropicProvider

composio = Composio(provider=AnthropicProvider())
client = anthropic.Anthropic()

session = composio.create(
    user_id="user_123",
    toolkits={"enable": ["gmail"]},
    tools={
        "gmail": {
            "enable": ["GMAIL_FETCH_EMAILS", "GMAIL_SEND_EMAIL"],
            "require_approval": ["GMAIL_SEND_EMAIL"],
        }
    },
)
tools = session.tools()


def ask_user(question):
    """Show one question in the terminal and return the user's answer."""
    print(question["message"])
    content = {}
    for name, field in question["requested_schema"]["properties"].items():
        choices = [choice["const"] for choice in field.get("oneOf", [])]
        content[name] = input(f"{field.get('title', name)} ({'/'.join(choices)}): ")
    return {"action": "accept", "content": content}


def run_tool(block):
    """Run one tool call, asking the user whenever Composio needs their input."""
    input_responses, request_state = None, None
    while True:
        try:
            result = session.execute(
                block.name,
                arguments=block.input,
                input_responses=input_responses,
                request_state=request_state,
            )
            break
        except ToolInputRequiredError as error:
            input_responses = {
                question_id: ask_user(question)
                for question_id, question in error.input_requests.items()
            }
            request_state = error.request_state

    return {
        "type": "tool_result",
        "tool_use_id": block.id,
        "content": json.dumps({"data": result.data, "error": result.error}),
    }


messages = [
    {"role": "user", "content": "Email priya@acme.com with the subject 'Q3 numbers' and say the report is ready."}
]
response = client.messages.create(
    model="claude-opus-4-6", max_tokens=4096, tools=tools, messages=messages
)

while response.stop_reason == "tool_use":
    messages.append({"role": "assistant", "content": response.content})
    messages.append({
        "role": "user",
        "content": [run_tool(block) for block in response.content if block.type == "tool_use"],
    })
    response = client.messages.create(
        model="claude-opus-4-6", max_tokens=4096, tools=tools, messages=messages
    )

for block in response.content:
    if block.type == "text":
        print(block.text)
```
</Tab>
<Tab value="TypeScript">
```typescript
// @noErrors
import Anthropic from '@anthropic-ai/sdk';
import { AnthropicProvider } from '@composio/anthropic';
import {
  Composio,
  ComposioToolInputRequiredError,
  type ToolRouterInputRequest,
  type ToolRouterSessionExecuteOptions,
} from '@composio/core';
import * as readline from 'node:readline/promises';

const composio = new Composio({ provider: new AnthropicProvider() });
const client = new Anthropic();
const terminal = readline.createInterface({ input: process.stdin, output: process.stdout });

const session = await composio.create('user_123', {
  toolkits: { enable: ['gmail'] },
  tools: {
    gmail: {
      enable: ['GMAIL_FETCH_EMAILS', 'GMAIL_SEND_EMAIL'],
      requireApproval: ['GMAIL_SEND_EMAIL'],
    },
  },
});
const tools = await session.tools();

// Show one question in the terminal and return the user's answer
async function askUser(question: ToolRouterInputRequest) {
  console.log(question.message);
  const { properties } = question.requestedSchema as {
    properties: Record<string, { title?: string; oneOf?: { const: string }[] }>;
  };
  const content: Record<string, string> = {};
  for (const [name, field] of Object.entries(properties)) {
    const choices = field.oneOf?.map((choice) => choice.const) ?? [];
    content[name] = await terminal.question(`${field.title ?? name} (${choices.join('/')}): `);
  }
  return { action: 'accept' as const, content };
}

// Run one tool call, asking the user whenever Composio needs their input
async function runTool(block: Anthropic.ToolUseBlock): Promise<Anthropic.ToolResultBlockParam> {
  let answers: ToolRouterSessionExecuteOptions = {};
  while (true) {
    try {
      const result = await session.execute(block.name, block.input as Record<string, unknown>, answers);
      return {
        type: 'tool_result',
        tool_use_id: block.id,
        content: JSON.stringify({ data: result.data, error: result.error }),
      };
    } catch (error) {
      if (!(error instanceof ComposioToolInputRequiredError)) throw error;
      const inputResponses: NonNullable<ToolRouterSessionExecuteOptions['inputResponses']> = {};
      for (const [questionId, question] of Object.entries(error.inputRequests)) {
        inputResponses[questionId] = await askUser(question);
      }
      answers = { inputResponses, requestState: error.requestState };
    }
  }
}

const messages: Anthropic.MessageParam[] = [
  { role: 'user', content: "Email priya@acme.com with the subject 'Q3 numbers' and say the report is ready." },
];
let response = await client.messages.create({
  model: 'claude-opus-4-6',
  max_tokens: 4096,
  tools,
  messages,
});

while (response.stop_reason === 'tool_use') {
  messages.push({ role: 'assistant', content: response.content });
  const results: Anthropic.ToolResultBlockParam[] = [];
  for (const block of response.content) {
    if (block.type === 'tool_use') results.push(await runTool(block));
  }
  messages.push({ role: 'user', content: results });
  response = await client.messages.create({
    model: 'claude-opus-4-6',
    max_tokens: 4096,
    tools,
    messages,
  });
}

for (const block of response.content) {
  if (block.type === 'text') console.log(block.text);
}
terminal.close();
```

## Approvals in MCP clients

Approvals use MCP [elicitation](https://modelcontextprotocol.io/specification/2026-07-28/client/elicitation), which lets a server ask the user for input through the client. When your agent connects to the session [over MCP](/docs/sessions-via-mcp), clients that support elicitation, like Claude Code, ask the user for you. With clients that don't, calls that need approval are denied. To run them without approval instead, set `no_elicitation_support_fallback` to `"allow"`:

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
session = composio.create(
    user_id="user_123",
    tools={
        "gmail": {
            "enable": ["GMAIL_FETCH_EMAILS", "GMAIL_SEND_EMAIL"],
            "require_approval": ["GMAIL_SEND_EMAIL"],
        }
    },
    experimental={"no_elicitation_support_fallback": "allow"},
)
```
</Tab>
<Tab value="TypeScript">
```typescript
// @noErrors
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: 'your_api_key' });
// ---cut---
const session = await composio.create('user_123', {
  tools: {
    gmail: {
      enable: ['GMAIL_FETCH_EMAILS', 'GMAIL_SEND_EMAIL'],
      requireApproval: ['GMAIL_SEND_EMAIL'],
    },
  },
  experimental: { noElicitationSupportFallback: 'allow' },
});
```
</Tab>
</Tabs>

## Limitations

- **Providers.** `handle_tool_calls` and framework providers don't support approval yet. Run tool calls with `session.execute()`, as in the example above.
- **Custom tools.** A [custom tool](/docs/extending-sessions/custom-tools-and-toolkits) can't pass an answer through `ctx.execute()`.
- **Proxy execute.** `session.proxy_execute()` is disabled for a toolkit when any of its tools can need approval.
