Adding enrichment, scraping, or media creation to your agent shouldn't mean asking every user to sign up for another provider, manage an API key, or buy a separate subscription. Instant tools run supported actions on Composio's provider accounts and charge your organization's Composio balance. Your users still connect their own accounts when a task needs their identity or private data.

Instant works through [Sessions](/docs/how-composio-works). New to Composio? Follow the [Quickstart](/docs/quickstart) for SDK and agent setup, then return here.

## Enable Instant

In [project Settings](https://dashboard.composio.dev/~/project/settings/general?utm_source=docs&utm_medium=content&utm_campaign=instant-tools), turn on **Instant Toolkits**. Check that your organization has an available balance in [Billing](https://dashboard.composio.dev/~/org/settings/billing?utm_source=docs&utm_medium=content&utm_campaign=instant-tools) before running a tool.

- **Project default:** off. A Session cannot override a project where Instant is off.
- **Once enabled:** eligible tools can use Instant in all Sessions, including existing Sessions. Existing Session restrictions still apply.
- **Session default:** omitting `instant` permits Instant usage. Set `instant=False` in Python or `instant: false` in TypeScript to prevent Instant charges for that Session.

<Callout type="info" title="Experimental access">
If the setting is unavailable, contact [support@composio.dev](mailto:support@composio.dev) to request access.
</Callout>

## Use Instant in your agent

Keep your existing Composio client and agent integration. For example, create a Session with Firecrawl available and pass its tools to your agent as usual:

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
session = composio.sessions.create(
    user_id="instant_demo",
    toolkits=["firecrawl"],
)
tools = session.tools()
```
</Tab>
<Tab value="TypeScript">
```typescript
import { Composio } from "@composio/core";
const composio = new Composio();
// ---cut---
const session = await composio.create("instant_demo", {
  toolkits: ["firecrawl"],
});
const tools = await session.tools();
```
</Tab>
</Tabs>

Ask your agent: “Read https://composio.dev and summarize what the company offers.” With Instant enabled and no existing Firecrawl connection, the agent can use a supported tool without asking you for a Firecrawl API key.

You don't need a separate Instant execution method. It works with `session.tools()`, `session.execute()`, and the Session's [MCP endpoint](/docs/sessions-via-mcp). For general toolkit filters and agent setup, see [Configuring Sessions](/docs/configuring-sessions) and the [Quickstart](/docs/quickstart).

To verify the call, find the Session's tool execution in the [logs API](/reference/api-reference/logs/postLogsToolExecution). `metadata.credential_source` should be `instant_account`; `metadata.instant_charge` records the charge. An agent's summary alone doesn't prove the tool ran through Instant.

## Find supported tools and rates

Instant support is **per tool**. A toolkit supporting Instant does not mean every tool in that toolkit supports it.

- [List toolkits](/reference/api-reference/toolkits/getToolkits) and filter `items` by `instant.supported == true` to find toolkits with Instant tools.
- [List tools](/reference/api-reference/tools/getTools) with `toolkit_slug`, `toolkit_versions=latest`, and `include_pricing=true`. Filter `items` by `instant.supported == true`.
- [Get a tool](/reference/api-reference/tools/getToolsByToolSlug) with `include_pricing=true` to check its support, rate, and input schema before executing it.

For example, check Firecrawl's scrape tool:

```bash
curl --get 'https://backend.composio.dev/api/v3.1/tools/FIRECRAWL_SCRAPE' \
  --header "x-api-key: $COMPOSIO_API_KEY" \
  --data-urlencode 'toolkit_versions=latest' \
  --data-urlencode 'include_pricing=true' \
  | jq '{slug, instant, input_parameters}'
```

Read the rate from `instant.price.description` and any discount from `instant.price.discount`. Both are strings when present; `discount` can be null. Missing pricing does not mean the tool is free.

Follow `next_cursor` when listing tools or toolkits, including pages with no Instant matches. Instant metadata is absent for older toolkit versions and ineligible tools. Neither `no_auth` nor `composio_managed_auth_schemes` indicates Instant support.

## Control Instant usage

The Session's top-level `toolkits` filter controls which toolkits your agent can use. The separate `instant` setting controls whether it can use Composio's Instant accounts for those tools.

### Turn Instant off

Your own connected accounts remain available when you disable Instant:

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
session.update(instant=False)
```
</Tab>
<Tab value="TypeScript">
```typescript
import { Composio } from "@composio/core";
const composio = new Composio();
const session = await composio.create("user_123");
// ---cut---
await session.update({ instant: false });
```
</Tab>
</Tabs>

<Callout type="warning" title="Updating a disabled Session">
Passing any `instant` object after `instant=false` re-enables Instant usage if the project allows it, even if you only set charge reporting. Keep `instant` as `false` when the Session must not spend. Omitting `instant` from an update preserves the existing policy.
</Callout>

### Allow or exclude specific toolkits and tools

Keep Exa and Firecrawl available, but allow Instant only for `EXA_SEARCH`:

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
session = composio.sessions.create(
    user_id="user_123",
    toolkits=["exa", "firecrawl"],
    instant={
        "toolkits": {"enable": ["exa"]},
        "tools": {"exa": {"enable": ["EXA_SEARCH"]}},
    },
)
```
</Tab>
<Tab value="TypeScript">
```typescript
import { Composio } from "@composio/core";
const composio = new Composio();
// ---cut---
const session = await composio.create("user_123", {
  toolkits: ["exa", "firecrawl"],
  instant: {
    toolkits: { enable: ["exa"] },
    tools: { exa: { enable: ["EXA_SEARCH"] } },
  },
});
```
</Tab>
</Tabs>

Use `disable` instead of `enable` to exclude the listed toolkits or tools. Each filter accepts one or the other, not both. Toolkit and tool filters intersect; they cannot enable anything excluded by the Session's top-level filters.

Omitting `instant.toolkits` leaves other eligible toolkits permitted. A `tools.exa` rule alone does not restrict Instant to Exa.

### Return the charge with a call

Charge reporting is off by default. To include the charge in a `session.execute()` response, set `return_instant_charge` in Python or `returnInstantCharge` in TypeScript:

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
session = composio.sessions.create(
    user_id="instant_demo",
    toolkits=["firecrawl"],
    instant={"return_instant_charge": True},
)
result = session.execute("FIRECRAWL_SCRAPE", arguments={"url": "https://composio.dev"})
if result.instant_charge is not None:
    print(result.instant_charge.amount, result.instant_charge.currency)
```
</Tab>
<Tab value="TypeScript">
```typescript
import { Composio } from "@composio/core";
const composio = new Composio();
// ---cut---
const session = await composio.create("instant_demo", {
  toolkits: ["firecrawl"],
  instant: { returnInstantCharge: true },
});
const result = await session.execute("FIRECRAWL_SCRAPE", { url: "https://composio.dev" });
console.log(result.instantCharge);
```
</Tab>
</Tabs>

The charge includes `amount`, `currency`, and `charged_by`. The amount is an exact USD decimal string. TypeScript exposes `instantCharge` as `unknown`. Turning charge reporting off does not stop billing or remove charges from logs and usage records.

## Know which account runs the tool

Composio uses your user's connection first, then an available shared connection, then an Instant account. Only calls through an Instant account incur an Instant charge. Your provider may separately bill calls made with your own account.

An explicitly selected account takes priority. A failed connected-account call does not fall back to Instant. Tools that don't support Instant use the normal connection flow.

Instant uses shared provider accounts, so tools exposing account history or other customers' data are excluded. Arbitrary proxy requests are not supported. Connect your own account for private data or account-specific actions. Inputs still go to the provider; Instant does not imply [zero data retention](/docs/security/zero-data-retention).

### Inspect or explicitly select an Instant account

Session search returns `instant_account.allowed_tool_slugs` (`instantAccount.allowedToolSlugs` in TypeScript) for a toolkit served by an Instant account. Other tools in that toolkit need your own connection.

To select Instant explicitly, pass `account="instant_account"` to Python `session.execute()`, or `{ account: "instant_account" }` as TypeScript execution options. On a single-account project, this must match an active connection for the toolkit in the Session. Project policy, Session policy, and tool eligibility still apply. A failed call does not fall back to another account.

Composio-managed auth is different: Composio supplies the OAuth app credentials, but your user still connects their own account. It does not establish Instant support.

## Balance, usage, and troubleshooting

Instant calls use your organization's prepaid balance, including on Enterprise. Check or add funds in [Billing](https://dashboard.composio.dev/~/org/settings/billing?utm_source=docs&utm_medium=content&utm_campaign=instant-tools). If your plan doesn't allow adding funds, upgrade or contact support.

- **Usage totals:** call the [project usage summary API](/reference/api-reference/projects/postProjectUsageSummary). Its top-level `instant_charge` is the total Instant charge as a USD string. An empty request body selects the last 30 days; use `from` and `to` in Unix milliseconds for another window.
- **Individual calls:** query the [execution logs API](/reference/api-reference/logs/postLogsToolExecution) with a `session_id` filter. Check `metadata.credential_source` and `metadata.instant_charge`. An absent charge is not proof that the call was free.
- **Instant unavailable:** check the project setting, Session restrictions, and the individual tool's eligibility on the latest version.
- **Balance exhausted:** Instant calls fail with HTTP 402 (`Metering_WalletBalanceExhausted`) once detected, without falling back to another account. Balance checks are asynchronous, not a strict spending cap. Calls using your own connected account can still run.
- **Failed or timed-out call:** check the execution log before retrying. The provider may have completed billable work. Contact [support@composio.dev](mailto:support@composio.dev) with the log ID if the result or charge is unclear.
