---
title: Prompt injection detection
description: Block prompt injection in tool results before it reaches your agent
keywords: [prompt injection, prompt_injection_check, hooks, firewall, guardrails, after_execute]
---

Prompt injection detection screens each tool result, and blocks it if it contains a prompt injection.

<Callout type="warn">
Prompt injection detection is in beta and available on paid plans, with [usage-based pricing](https://composio.dev/pricing/platform).
</Callout>

To turn it on, add a [hook](/docs/hooks) with the `prompt_injection_check` handler:

<Tabs groupId="language" items={['Python', 'TypeScript', 'API']} persist>
<Tab value="Python">
```python
session = composio.create(
    user_id="user_123",
    hooks=[
        {
            "id": "block_injection",
            "type": "after_execute",
            "applies_to": "all",
            "handler": {"type": "prompt_injection_check", "action": "block"},
        },
    ],
)
```
</Tab>
<Tab value="TypeScript">
```typescript
// @noErrors
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: 'your_api_key' });
// ---cut---
const session = await composio.create('user_123', {
  hooks: [
    {
      id: 'block_injection',
      type: 'after_execute',
      appliesTo: 'all',
      handler: { type: 'prompt_injection_check', action: 'block' },
    },
  ],
});
```
</Tab>
<Tab value="API">
```bash
curl -X POST https://backend.composio.dev/api/v3.1/tool_router/session \
  -H "x-api-key: $COMPOSIO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "user_123",
    "hooks": [
      {
        "id": "block_injection",
        "type": "after_execute",
        "applies_to": "all",
        "handler": {"type": "prompt_injection_check", "action": "block"}
      }
    ]
  }'
```
</Tab>
</Tabs>

`prompt_injection_check` only works in `after_execute` hooks, since tool results are where outside content reaches your agent.
