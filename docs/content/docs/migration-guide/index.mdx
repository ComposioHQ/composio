Not sure whether to use sessions or call tools directly? See [Sessions vs Direct Execution](/docs/sessions-vs-direct-execution) before you pick a guide.

## Available migration guides

<Accordions>
  <Accordion title="Migrate from No Auth to Instant">
    Move shared-access workflows to Instant with your existing agents and Sessions.

    [View No Auth to Instant migration guide →](/docs/migration-guide/no-auth-to-instant)
  </Accordion>

  <Accordion title="Migrating from Direct Tools to Sessions">
    Move from manual tool fetching and execution to the sessions paradigm. Your existing auth configs and connected accounts carry over.

    [View Direct Tools migration guide →](/docs/migration-guide/direct-to-sessions)
  </Accordion>

  <Accordion title="Migrating from API v3 to v3.1">
    Move direct REST calls to `/api/v3.1/`, where tool endpoints default to the latest toolkit version. SDK users don't need to change anything.

    [View API v3.1 migration guide →](/docs/migration-guide/api-v3-to-v3-1)
  </Accordion>

  <Accordion title="Migrating from MCP servers to Sessions">
    Move from per-toolkit MCP server configs (`composio.mcp.create` / `composio.mcp.generate`) to sessions. Your tools, auth configs, and connected accounts carry over — no re-auth.

    [View MCP servers migration guide →](/docs/migration-guide/mcp-servers-to-sessions)
  </Accordion>

  <Accordion title="Migrating from Experimental Tool Router">
    Migrate from `composio.experimental.tool_router` to the stable sessions API.

    [View Tool Router migration guide →](/docs/migration-guide/tool-router-beta)
  </Accordion>

  <Accordion title="Toolkit versioning migration">
    Migrate to use the toolkit versioning system.

    [View versioning migration guide →](/docs/migration-guide/toolkit-versioning)
  </Accordion>

  <Accordion title="New SDK migration">
    Migrate from the old Composio SDK to the new SDK, including breaking changes, new features, and updated APIs.

    [View SDK migration guide →](/docs/migration-guide/new-sdk)
  </Accordion>
</Accordions>

## Deprecations

- **Toolkit versions** are deprecated 12 months after they're published and stop working 3 months later. Both SDKs log a warning when a call resolves to a deprecated version. See [Deprecation and sunset](/docs/tools-direct/toolkit-versioning#deprecation-and-sunset).
- **Tools** backed by deprecated upstream endpoints have `deprecated.is_deprecated` set to `true` in the [tool metadata](/reference/api-reference/tools). They may be removed in a future toolkit version.
- **The legacy SDK** (`composio-core`) is no longer maintained. Follow the [new SDK migration guide](/docs/migration-guide/new-sdk).
