Every tool has a **tag** that describes the action it takes: reading, creating, updating or deleting. Sessions use tags to allow, block or require approval for tools by type, instead of listing tools one by one.

## Tags

| Tag | The tool | For example |
| --- | --- | --- |
| `readOnlyHint` | Reads data and changes nothing | Fetch emails, list pull requests, export a report |
| `createHint` | Adds something new | Send an email, create an issue |
| `updateHint` | Changes something that already exists | Edit an issue, rename a file |
| `destructiveHint` | Deletes something | Delete a file, delete a repository |

## How tools are tagged

Composio tags each tool with the most severe action it can take. A tool that can delete something is tagged `destructiveHint`, even if it also updates. A tool that changes something that already exists is tagged `updateHint`. A tool that only adds something new is tagged `createHint`. Every other tool is tagged `readOnlyHint`.

A tool's tag reflects what changes for the user, not the HTTP method of the API behind it:

- A tool that sends a search query with `POST` and returns results is `readOnlyHint`.
- A tool that cancels or resets something with `GET` is `updateHint` or `destructiveHint`.
- A tool that computes, converts, summarizes or exports data without changing anything is `readOnlyHint`.
- A tool that adds an item to a list or folder is `createHint`.

In MCP toolkits, such as `granola_mcp` and [custom MCP toolkits](/docs/extending-sessions/custom-mcp), `readOnlyHint` comes from the MCP server's tool annotations, and Composio tags the server's other tools when the toolkit syncs.

## Viewing a tool's tags

[Get a tool](/reference/api-reference/tools/getToolsByToolSlug) returns its tags in the `tags` field. Pass `version=latest` to see the tags a session uses.

## Using tags in a session

A session can allow, block or require approval for tools by their tag, and override this for specific toolkits:

- To block tools, see [Filtering tools by tags](/docs/configuring-sessions#filtering-tools-by-tags).
- To require approval, see [Approval mode](/docs/approval-mode).
