## Create an MCP server

<Steps>
  <Step>
    ### Initialize Composio

    {/* code-example: no-api reason="SDK client construction; the REST API takes the key as an x-api-key header on each request" */}
    <Tabs groupId="language" items={['Python', 'TypeScript']} persist>
      <Tab value="Python">
```python
from composio import Composio

composio = Composio(api_key="YOUR_API_KEY")
```
      </Tab>
      <Tab value="TypeScript">
```typescript
import { Composio } from '@composio/core';

const composio = new Composio({
  apiKey: process.env.COMPOSIO_API_KEY
});
```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### Create server configuration

    <Callout type="warn">
    **Before you begin:** [Create an auth configuration](/docs/auth-configuration/custom-auth-configs) for your toolkit.
    </Callout>

    <Tabs groupId="language" items={['Python', 'TypeScript', 'API']} persist>
      <Tab value="Python">
```python
server = composio.mcp.create(
    name="my-gmail-server",
    toolkits=[{
        "toolkit": "gmail",
        "auth_config": "ac_xyz123"
    }],
    allowed_tools=["GMAIL_FETCH_EMAILS", "GMAIL_SEND_EMAIL"]
)

print(f"Server created: {server.id}")
```
      </Tab>
      <Tab value="TypeScript">
```typescript
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: process.env.COMPOSIO_API_KEY });
// ---cut---
const server = await composio.mcp.create("my-gmail-server", {
  toolkits: [
    {
      authConfigId: "ac_xyz123",
      toolkit: "gmail"
    }
  ],
  allowedTools: ["GMAIL_FETCH_EMAILS", "GMAIL_SEND_EMAIL"]
});

console.log(`Server created: ${server.id}`);
```
      </Tab>
      <Tab value="API">
```bash
SERVER_ID=$(curl -s -X POST https://backend.composio.dev/api/v3.1/mcp/servers/custom \
  -H "x-api-key: $COMPOSIO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-gmail-server",
    "toolkits": ["gmail"],
    "auth_config_ids": ["ac_xyz123"],
    "allowed_tools": ["GMAIL_FETCH_EMAILS", "GMAIL_SEND_EMAIL"],
    "managed_auth_via_composio": true
  }' | jq -r '.id')

echo "Server created: $SERVER_ID"
```
      </Tab>
    </Tabs>

    <Callout type="info">
    You can also create and manage MCP configs from the [Composio dashboard](https://dashboard.composio.dev/~/org/connect/clients?utm_source=docs&utm_medium=content&utm_campaign=docs-single-toolkit-mcp).
    </Callout>
  </Step>

  <Step>
    ### Generate user URLs

    <Callout type="warn">
    Users must authenticate with the toolkits configured in your MCP server first. See [authentication](/docs/authentication) for details.
    </Callout>

    <Tabs groupId="language" items={['Python', 'TypeScript', 'API']} persist>
      <Tab value="Python">
```python
instance = composio.mcp.generate(user_id="user-123", mcp_config_id=server.id)

print(f"MCP Server URL: {instance['url']}")
```
      </Tab>
      <Tab value="TypeScript">
```typescript
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: process.env.COMPOSIO_API_KEY });
const server = { id: 'my-gmail-server' };
// ---cut---
const instance = await composio.mcp.generate("user-123", server.id);

console.log("MCP Server URL:", instance.url);
```
      </Tab>
      <Tab value="API">
```bash
curl -s -X POST https://backend.composio.dev/api/v3.1/mcp/servers/generate \
  -H "x-api-key: $COMPOSIO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"mcp_server_id": "'"$SERVER_ID"'", "user_ids": ["user-123"], "managed_auth_by_composio": true}' \
  | jq -r '.user_ids_url[0]'
```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### Use with AI providers

    <Callout type="info">
    Pass an `x-api-key` header when connecting to Composio MCP. This is required when `require_mcp_api_key` is enabled (default for newly created organizations).
    </Callout>

    <Callout type="warn">
    For consumer connections, use `https://connect.composio.dev/mcp`, not this URL.
    </Callout>

    Set `COMPOSIO_MCP_URL` to the URL returned by the generate step, and keep `COMPOSIO_API_KEY` on the server. Don't construct the MCP URL from a server ID.

    <Tabs items={['OpenAI', 'Anthropic', 'Mastra']}>
      <Tab value="OpenAI">
{/* code-example: no-api reason="OpenAI Responses configures a remote MCP tool in an external model client, not through a Composio REST operation" */}
<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
```python
import os
from openai import OpenAI

client = OpenAI()
response = client.responses.create(
    model="gpt-5.4",
    tools=[{
        "type": "mcp",
        "server_label": "composio-server",
        "server_url": os.environ["COMPOSIO_MCP_URL"],
        "headers": {"x-api-key": os.environ["COMPOSIO_API_KEY"]},
        "require_approval": "never",
    }],
    input="What are my latest emails?",
)
print(response.output_text)
```
</Tab>
<Tab value="TypeScript">
```typescript
import OpenAI from 'openai';

const mcpServerUrl = process.env.COMPOSIO_MCP_URL;
const apiKey = process.env.COMPOSIO_API_KEY;
if (!mcpServerUrl || !apiKey) throw new Error('Set COMPOSIO_MCP_URL and COMPOSIO_API_KEY');
const client = new OpenAI();
const response = await client.responses.create({
  model: 'gpt-5.4',
  tools: [{
    type: 'mcp',
    server_label: 'composio-server',
    server_url: mcpServerUrl,
    headers: { 'x-api-key': apiKey },
    require_approval: 'never',
  }],
  input: 'What are my latest emails?',
});
console.log(response.output_text);
```
</Tab>
</Tabs>
      </Tab>
      <Tab value="Anthropic">
{/* code-example: no-api reason="Anthropic's hosted MCP connector is an external model API integration and cannot forward the required Composio header" */}
<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
<Tab value="Python">
<Callout type="info">
Anthropic's hosted MCP connector accepts a Bearer `authorization_token`, not arbitrary headers. Its Python `mcp_servers` options cannot send the `x-api-key` required by [Composio MCP servers](/reference/api-reference/mcp). Use the [Claude Agent SDK HTTP transport](/docs/sessions-via-mcp#wire-it-into-your-framework), which forwards `headers`, instead.
</Callout>
</Tab>
<Tab value="TypeScript">
<Callout type="info">
The TypeScript Anthropic SDK has the same hosted-connector limitation: `mcp_servers` accepts `authorization_token`, not `headers`. It cannot send the `x-api-key` required by [Composio MCP servers](/reference/api-reference/mcp). Use the [Claude Agent SDK HTTP transport](/docs/sessions-via-mcp#wire-it-into-your-framework) with the generated URL and headers instead.
</Callout>
</Tab>
</Tabs>
      </Tab>
      <Tab value="Mastra">
{/* code-example: single-language reason="Mastra is a TypeScript agent framework and has no Python SDK" */}
```typescript
import { MCPClient } from '@mastra/mcp';
import { Agent } from '@mastra/core/agent';

const mcpServerUrl = process.env.COMPOSIO_MCP_URL;
const apiKey = process.env.COMPOSIO_API_KEY;
if (!mcpServerUrl || !apiKey) throw new Error('Set COMPOSIO_MCP_URL and COMPOSIO_API_KEY');
const client = new MCPClient({
  id: 'mcp-client',
  servers: {
    composio: {
      url: new URL(mcpServerUrl),
      requestInit: { headers: { 'x-api-key': apiKey } },
    },
  },
});
try {
  const agent = new Agent({
    id: 'assistant',
    name: 'Assistant',
    instructions: 'You are a helpful assistant that can read and manage emails.',
    model: 'openai/gpt-5.4',
    tools: await client.listTools(),
  });
  const response = await agent.generate('What are my latest emails?');
  console.log(response.text);
} finally {
  await client.disconnect();
}
```

## Server management

### List servers

<Tabs groupId="language" items={['Python', 'TypeScript', 'API']} persist>
  <Tab value="Python">
```python
servers = composio.mcp.list(limit=10, page_no=1)
print(f"Found {len(servers['items'])} servers")

# Filter by toolkit
gmail_servers = composio.mcp.list(toolkits="gmail", limit=20, page_no=1)
```
  </Tab>
  <Tab value="TypeScript">
```typescript
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: 'your_api_key' });
// ---cut---
const servers = await composio.mcp.list({
  toolkits: [],
  authConfigs: [],
  limit: 10,
  page: 1
});
console.log(`Found ${servers.items.length} servers`);

// Filter by toolkit
const gmailServers = await composio.mcp.list({
  toolkits: ["gmail"],
  authConfigs: [],
  limit: 20,
  page: 1
});
```
  </Tab>
  <Tab value="API">
```bash
curl -X GET "https://backend.composio.dev/api/v3.1/mcp/servers?limit=10&page_no=1" \
  -H "x-api-key: $COMPOSIO_API_KEY"

# Filter by toolkit
curl -X GET "https://backend.composio.dev/api/v3.1/mcp/servers?toolkits=gmail&limit=20&page_no=1" \
  -H "x-api-key: $COMPOSIO_API_KEY"
```
  </Tab>
</Tabs>

  <Tab value="Python">
```python
updated = composio.mcp.update(
    server_id="mcp_server_id",
    name="updated-name",
    allowed_tools=["GMAIL_FETCH_EMAILS", "GMAIL_SEARCH_EMAILS"]
)
```
  </Tab>
  <Tab value="TypeScript">

import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: 'your_api_key' });

### Delete a server

<Tabs groupId="language" items={['Python', 'TypeScript', 'API']} persist>
  <Tab value="Python">
```python
result = composio.mcp.delete("mcp_server_id")
if result['deleted']:
    print("Server deleted")
```
  </Tab>
  <Tab value="TypeScript">
```typescript
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: 'your_api_key' });
// ---cut---
const result = await composio.mcp.delete("mcp_server_id");
if (result.deleted) {
  console.log("Server deleted");
}
```
  </Tab>
  <Tab value="API">
```bash
curl -X DELETE https://backend.composio.dev/api/v3.1/mcp/mcp_server_id \
  -H "x-api-key: $COMPOSIO_API_KEY"
```
