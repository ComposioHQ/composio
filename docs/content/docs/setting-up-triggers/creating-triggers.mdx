A trigger watches for one event (like `GITHUB_COMMIT_EVENT`) on one user's connected account. Create one, and events start flowing to your [subscription or webhook URL](/docs/setting-up-triggers/subscribing-to-events). For the bigger picture, see [Triggers](/docs/triggers).

<Callout type="info" title="Prerequisites">
- An [auth config](/docs/authentication#behind-the-scenes) for the toolkit you want to monitor
- A [connected account](/docs/authentication) for the user whose events you want to capture
</Callout>

## Inspect the trigger type

Each trigger type declares the config it needs. Check it before you create, so you pass the right fields.

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
  <Tab value="Python">
```python
from composio import Composio

composio = Composio()

trigger_type = composio.triggers.get_type("GITHUB_COMMIT_EVENT")
print(trigger_type.config)
# {"properties": {"owner": {...}, "repo": {...}}, "required": ["owner", "repo"]}
```
  </Tab>
  <Tab value="TypeScript">
```typescript
import { Composio } from '@composio/core';

const composio = new Composio();

const triggerType = await composio.triggers.getType('GITHUB_COMMIT_EVENT');
console.log(triggerType.config);
// {"properties": {"owner": {...}, "repo": {...}}, "required": ["owner", "repo"]}
```
  </Tab>
</Tabs>

## Create the trigger

Pass the user, the trigger slug, and the config the type requires.

<Tabs groupId="language" items={['Python', 'TypeScript']} persist>
  <Tab value="Python">
```python
from composio import Composio

composio = Composio()
user_id = "user-id-123435"

trigger = composio.triggers.create(
    slug="GITHUB_COMMIT_EVENT",
    user_id=user_id,
    trigger_config={"owner": "your-repo-owner", "repo": "your-repo-name"},
)
print(f"Trigger created: {trigger.trigger_id}")
```
  </Tab>
  <Tab value="TypeScript">
```typescript
import { Composio } from '@composio/core';

const composio = new Composio();
const userId = 'user-id-123435';

const trigger = await composio.triggers.create(userId, 'GITHUB_COMMIT_EVENT', {
  triggerConfig: { owner: 'your-repo-owner', repo: 'your-repo-name' },
});
console.log(`Trigger created: ${trigger.triggerId}`);
```
  </Tab>
</Tabs>

<Callout>
Pass a `user_id` and the SDK finds that user's connected account for the toolkit automatically. If the user has more than one, it uses the most recently created account. Pass a `connected_account_id`/`connectedAccountId` to pick a specific one.
</Callout>

<Callout>
Trigger instances default to the `'latest'` toolkit version. If you parse payloads against a fixed schema, pin a version at SDK initialization. See [Toolkit Versioning](/docs/tools-direct/toolkit-versioning#choosing-between-latest-and-a-pinned-version).
</Callout>

That's it. The trigger is active. Next, [receive its events](/docs/setting-up-triggers/subscribing-to-events).

## From the dashboard

1. Go to [Auth Configs](https://dashboard.composio.dev/~/project/auth-configs) and select the auth config for the toolkit.
2. Open **Active Triggers** and click **Create Trigger**.
3. Select the connected account to create the trigger for.
4. Choose a trigger type and fill in its config.
5. Click **Create Trigger**.
