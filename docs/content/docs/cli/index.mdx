The installer verifies the release and configures PATH for future terminals. On Linux and macOS, it also sets up plugins for detected, supported agent hosts. Login is a separate step.

## Then, run your first command

<div className="grid gap-4 md:grid-cols-2">
<div className="rounded-xl border bg-fd-card p-5">

<span id="verify-the-installation" className="scroll-m-28" />
<span id="log-in" className="scroll-m-28" />

### 1. Verify and log in

Open a new terminal, then run:

```bash
composio --version
composio login
```

If your shell cannot find `composio`, use the absolute path printed by the installer. See [shell setup](/docs/cli/installation#shell-setup-overrides).

</div>
<div className="rounded-xl border bg-fd-card p-5">

### 2. Find a tool

Search for tools by the task you want to complete:

```bash
composio search "Find tools for Gmail"
```

Choose a tool from the results. Follow [search, connect, and execute](/docs/cli/workflows#search-connect-and-execute-tools) to inspect its schema, connect your account, and run it.

</div>
</div>

For browserless human login, use `composio login --no-wait` to get an authorization URL. Use `composio login --poll --timeout <seconds>` to bound the wait. If authorization is still pending when the timeout expires, the CLI prints the URL and the command to resume polling. See [Log in with a human](/docs/agent-setup/unattended-authentication#log-in-with-a-human).

For an unattended agent, use a saved CLI login or supply an existing user API key through `COMPOSIO_USER_API_KEY`. [Authenticate an unattended agent](/docs/agent-setup/unattended-authentication) covers application API key setup and live-tool verification.
