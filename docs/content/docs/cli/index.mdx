Use the Composio CLI to connect apps and run tools from your terminal, Codex, or Claude Code. The CLI also powers the [Composio agent plugins](/docs/agent-plugins).

## Install

Choose the system where you will run the CLI. Your browser selects a tab automatically; mobile devices and unknown systems start on Linux.

<CliInstallTabs>
<TabsContent value="linux">

Requires `curl` and `unzip`. Supports Linux x64 and ARM64.

```bash
curl -fsSL https://composio.dev/install | sh
```

</TabsContent>
<TabsContent value="macos">

Requires `curl` and `unzip`. Supports Intel and Apple Silicon Macs.

```bash
curl -fsSL https://composio.dev/install | sh
```

</TabsContent>
<TabsContent value="windows">

**Experimental:** requires Windows 10 version 1809 or newer and an x64 CPU with SSE4.2. Windows ARM64 is not supported. Run in PowerShell:

```powershell
irm https://raw.githubusercontent.com/ComposioHQ/composio/next/install.ps1 | iex
```

For a fully supported setup, use the Linux installer inside [WSL](https://learn.microsoft.com/windows/wsl/install). See [Windows support and installer options](/docs/cli/installation#windows-x64-experimental).

</TabsContent>
</CliInstallTabs>

The installer verifies the release and configures PATH for future terminals. On Linux and macOS, it also sets up plugins for detected, supported agent hosts. Login is a separate step.

Need a pinned version, custom directory, or CI install? See [installation options](/docs/cli/installation).

## Verify the installation

Open a new terminal and check the installed version:

```bash
composio --version
```

If your shell cannot find `composio`, run the absolute path printed by the installer. See [shell setup overrides](/docs/cli/installation#shell-setup-overrides) for PATH configuration.

## Log in

```bash
composio login
```

For an unattended agent, use [`composio login --agent`](/docs/agent-setup/unattended-authentication). That guide covers constraints, application API key setup, and live-tool verification.

### Set up your agent

If you skipped plugin setup or installed an agent host later, run:

```bash
composio setup --target auto
```

`auto` detects supported agents. Use `--target codex` or `--target claude` to choose one. Setup asks before changing local files. Add `--yes` in an agent, script, or CI job.

`composio login` installs the standalone CLI skill for Claude Code by default. For Codex, prefer the native plugin through `composio setup --target codex`. See [Agent plugins](/docs/agent-plugins) for host-specific details.

If you need the standalone skill without the native plugin, install it for your host:

```bash
composio setup skill claude
composio setup skill codex
```

## Update

```bash
composio upgrade
```

This replaces the bundle in place. Pass a version, such as `composio upgrade 0.3.1`, to pin a release, or `--beta` for the latest prerelease.

If your installed CLI is too old to upgrade, the command stops before changing anything and prints an install command. Rerun the [installer](#install).

## Help

Use `--help` on the root command or any subcommand:

```bash
composio --help
composio help
composio execute --help
composio run --help
composio dev projects switch --help
```
