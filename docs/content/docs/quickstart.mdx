Build a Python agent that stars a GitHub repository. Composio gives the agent the tools it needs and handles the GitHub connection.

## Prerequisites

You need:

- A terminal with [`uv`](https://docs.astral.sh/uv/) installed. `uv` installs and manages the required Python version for this project.
- A `COMPOSIO_API_KEY` from [Composio Settings](https://dashboard.composio.dev/~/project/settings/api-keys?utm_source=docs&utm_medium=content&utm_campaign=docs-quickstart).
- An `OPENAI_API_KEY` from [OpenAI](https://platform.openai.com/api-keys).

## Build and run the agent

<Steps>
<Step>
<StepTitle>Initialize the project</StepTitle>

Create an application with Python 3.10 or newer, then enter the new directory:

```bash
uv init --app --python 3.10 composio-quickstart
cd composio-quickstart
```

</Step>
<Step>
<StepTitle>Install the dependencies</StepTitle>

```bash
uv add python-dotenv composio composio-openai-agents openai-agents
```

</Step>
<Step>
<StepTitle>Add your API keys</StepTitle>

Create `.env` in the project root:

```bash title=".env"
COMPOSIO_API_KEY=your_composio_api_key
OPENAI_API_KEY=your_openai_api_key
```

Keep the file out of source control:

```bash
echo ".env" >> .gitignore
```

</Step>
<Step>
<StepTitle>Create the agent</StepTitle>

Replace the generated `main.py` with this complete program:

```python title="main.py"
from agents import Agent, Runner
from composio import Composio
from composio_openai_agents import OpenAIAgentsProvider
from dotenv import load_dotenv

load_dotenv()

composio = Composio(provider=OpenAIAgentsProvider())
session = composio.create(user_id="quickstart-user")
tools = session.tools()

agent = Agent(
    name="GitHub assistant",
    instructions=(
        "Use Composio tools to complete the request. "
        "If GitHub is not connected, return the connection link to the user."
    ),
    tools=tools,
)

result = Runner.run_sync(
    starting_agent=agent,
    input="Star the composiohq/composio repository on GitHub.",
)

print(result.final_output)
```

</Step>
<Step>
<StepTitle>Run the agent</StepTitle>

```bash
uv run main.py
```

If GitHub is not connected for `quickstart-user`, the agent returns a Connect Link. Open that link, approve access to GitHub, then run the same command again:

```bash
uv run main.py
```

Composio stores the connection under `quickstart-user`, so the next run can reuse it. If GitHub is already connected for this ID, the action can complete immediately.

</Step>
<Step>
<StepTitle>Confirm the result</StepTitle>

The agent should confirm that it starred the repository. You can also check that **Starred** is selected on the [`ComposioHQ/composio` repository](https://github.com/ComposioHQ/composio). To inspect the tool request, response, and timing, use the [Logs API](/reference/api-reference/logs).

</Step>
</Steps>

## What the code does

- `OpenAIAgentsProvider` converts Composio tools into the format OpenAI Agents expects.
- `composio.create()` creates a [session](/docs/how-composio-works) for one user. The session handles tool discovery, authentication, and execution.
- `session.tools()` gives the agent a small set of meta tools that can find and run tools from [1000+ toolkits](/toolkits).

<Callout type="warn" title="Use a real user ID in production">
`quickstart-user` is only for this local example. In your application, pass the signed-in user's stable database ID so every person's connections and tool calls stay isolated.
</Callout>
