## Quick Start

### Async Python

```python
import asyncio
from composio import AsyncComposio


async def main():
    async with AsyncComposio() as composio:
        session = await composio.create(user_id="user-123")
        tools = await session.tools()
        print(len(tools))
        result = await composio.tools.execute(
            "GITHUB_LIST_STARGAZERS",
            arguments={"owner": "ComposioHQ", "repo": "composio"},
            user_id="user-123",
            version="20250909_00",
        )


asyncio.run(main())
```

### Sync Python

```python
from composio import Composio

composio = Composio()
session = composio.create(user_id="user-123")
tools = session.tools()

    version="20250909_00",
)
```

### after_execute

Build an execution-result modifier.  Your callback receives `(tool, toolkit, response)` and returns a `ToolExecutionResponse` dictionary. Check `response["successful"]`, not the session model's `result_type` attribute. Session adapters retain `log_id` and `result_type` as dictionary keys. Serialize with `json.dumps(response)` if needed; it is not a provider message. Register this on tool execution or `session.tools(modifiers=[...])`. Calling `session.execute` directly does not invoke it.

[View source](https://github.com/composiohq/composio/blob/next/python/composio/core/models/_modifiers.py#L239)

```python signature

    ...
```

### before_file_upload

Build a `Modifier` for the file-upload hook (same scoping pattern as `before_execute`).  Your callable may take **either**:  - a single `context` argument (`BeforeFileUploadContext`) — the preferred form, exposes `context["source"]` (`"path"` or `"url"`), or - three positional arguments `(path, tool, toolkit)` — legacy form, kept for back-compat.  Return a new path/URL string to substitute, or `False` to abort the upload (raises `FileUploadAbortedError`).  Pass the returned `Modifier` in `modifiers=[...]` on `composio.core.models.tools.Tools.execute` or `tools.get`. Multiple such modifiers are composed in list order.

[View source](https://github.com/composiohq/composio/blob/next/python/composio/core/models/_modifiers.py#L327)

```python signature

def my_modifier(...):
    ...
```
