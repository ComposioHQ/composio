## Methods

### create()

Create a session for a user.  This is the shortcut for `ToolRouter.create`, with the same keyword arguments and return types. Inspect either method on its class without constructing a client. `tools` is a toolkit-keyed map; `toolkits` accepts a list or an enable/disable policy.  See `help(ToolRouter.create)` for the full configuration reference. Creating a session requires credentials and makes a backend request.

```python
def create(*, user_id: str, toolkits: Union[List[str], ToolRouterToolkitsEnableConfig, ToolRouterToolkitsDisableConfig, ToolRouterToolkitsRequireApprovalConfig] | None = ..., tools: Dict[str, ToolRouterToolsConfig] | None = ..., tags: ToolRouterConfigTags | None = ..., manage_connections: Union[bool, ToolRouterManageConnectionsConfig] | None = ..., auth_configs: Dict[str, str] | None = ..., connected_accounts: Dict[str, Union[str, List[str]]] | None = ..., sandbox: ToolRouterSandboxConfig | None = ..., workbench: ToolRouterWorkbenchConfig | None = ..., multi_account: ToolRouterMultiAccountConfig | None = ..., proxy_execute: Union[bool, ToolRouterProxyExecuteConfig] | None = ..., hooks: List[ToolRouterHook] | None = ..., preload: ToolRouterPreloadConfig | None = ..., session_preset: SessionPreset | None = ..., experimental: ToolRouterExperimentalConfig | None = ..., instant: Union[Literal[False], ToolRouterInstantConfig] | None = ..., mcp: bool = ...) -> ToolRouterSession[TTool, TToolCollection]
```
