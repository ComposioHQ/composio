### get_many()

Fetch several toolkits by slug in one request.

```python
def get_many(slugs: Sequence[str], category: str | None = ..., managed_by: Literal['composio', 'all', 'project' | None] = ..., sort_by: Literal['usage', 'alphabetically' | None] = ..., limit: float | None = ..., cursor: str | None = ...) -> List[Any]
```

**Parameters**

| Name | Type |
|------|------|
| `slugs` | `Sequence[str]` |
| `category?` | `str \| None` |
| `managed_by?` | `Literal['composio', 'all', 'project' \| None]` |
| `sort_by?` | `Literal['usage', 'alphabetically' \| None]` |
| `limit?` | `float \| None` |
| `cursor?` | `str \| None` |

**Returns**

`List[Any]` — The matching toolkits.

**Example**

```python
toolkits = composio.toolkits.get_many(["github", "slack"])
for toolkit in toolkits:
    print(toolkit.slug, toolkit.name)
```

### recommend_scopes()

Recommend the OAuth scopes to request so a connection can run the given tools. Experimental — the API marks this endpoint beta.

```python
def recommend_scopes(toolkit_slug: str, params: toolkit_recommend_scopes_params.ToolkitRecommendScopesParams = ...) -> toolkit_recommend_scopes_response.ToolkitRecommendScopesR...
```

**Parameters**

| Name | Type |
|------|------|
| `toolkit_slug` | `str` |
| `params?` | `toolkit_recommend_scopes_params.ToolkitRecommendScopesParams` |

**Returns**

`toolkit_recommend_scopes_response.ToolkitRecommendScopesR...` — The `least_privilege` and `fewest` scope sets plus the `conditional` scopes, under `.scopes`.

**Example**

```python
recommendation = composio.toolkits.recommend_scopes(
    "gmail",
    tools=["GMAIL_SEND_EMAIL", "GMAIL_FETCH_EMAILS"],
)
print(recommendation.scopes.least_privilege)
```


**Parameters**

|------|------|
| `toolkit_slug` | `str` |

**Returns**

`toolkit_retrieve_scopes_grant_context_response.ToolkitRet...` — `grant_context_dimensions` and `default_grant_context`.

**Example**
