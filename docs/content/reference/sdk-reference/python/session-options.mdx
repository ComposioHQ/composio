Generated from `composio==0.28.0`.

Choose the contract for the Session operation you're using. Create input, PATCH input, and returned config are not interchangeable.

```python
from composio import Composio

composio = Composio()
session = composio.create(user_id="user_123", toolkits=["github"])
config = session.update(toolkits={"enable": []})
print(config.user_id)
```

## Contracts

| Contract | Entry point | Omission and shape |
| --- | --- | --- |
| [Create input](/reference/sdk-reference/python/session-create-options#create-input) | `composio.create()` / `composio.sessions.create()` | Optional policy blocks default to `None`. Python has no saved-config `config` create parameter. |
| [PATCH input](/reference/sdk-reference/python/session-update-options#update-input) | `session.update()` | Omit to preserve a setting; `None` removes an override where supported. Supplied maps replace stored maps. Empty allowlists deny all. Instant accepts `False` or an object, not `None`. |
| [Returned config](/reference/sdk-reference/python/session-config#returned-config) | `session.config` / `session.update()` return value | SDK `ToolRouterSessionConfig` Protocol. Filters use `enabled` / `disabled`; sandbox settings use `workbench`. |

Each contract page includes all its reachable nested definitions, exact type imports, and source docstrings. The returned Session config is distinct from saved Session configs.
