## Returned config

`session.config` and the value returned by `session.update()` use the SDK's `ToolRouterSessionConfig` Protocol. This is a read shape, not a create input. Returned filters use `enabled` / `disabled`; input filters use `enable` / `disable`. The returned sandbox block is named `workbench`.

See [ToolRouterSessionConfig](#tool-router-session-toolroutersessionconfig) for every returned field.

## Nested definitions

Required keys, nullable values, and model defaults are shown independently. A response model's `None` default is not a server policy default. Source docstrings describe server defaults where specified.
