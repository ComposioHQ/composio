## Usage

Access this class through the `composio.files` property in Node.js runtimes:

```typescript
const composio = new Composio({ apiKey: 'your-api-key' });
const file = await composio.files.upload({
  file: './report.pdf',
  toolSlug: 'GOOGLE_DRIVE_UPLOAD_FILE',
  toolkitSlug: 'google_drive',
});
```

## Methods

### download()

Download a file from S3 and return the file data.

```typescript
async download(params: { s3Url: string; toolSlug: string; mimeType: string; }): Promise<FileDownloadData>
```

**Parameters**

| Name | Type | Description |
|------|------|-------------|
| `params` | `\{ s3Url: string; toolSlug: string; mimeType: string; \}` | The download parameters. |

**Returns**

`Promise<FileDownloadData>` — The file data.

---

### upload()

Upload a file and return the file data.

```typescript
async upload(params: { file: File | string; toolSlug: string; toolkitSlug: string; }): Promise<FileUploadData>
```

**Parameters**

| Name | Type | Description |
|------|------|-------------|
| `params` | `\{ file: File | string; toolSlug: string; toolkitSlug: string; \}` | The upload parameters. |

**Returns**

`Promise<FileUploadData>` — The uploaded file data.

**Example**

```typescript
const fileData = await composio.files.upload({
  file: 'path/to/file.pdf',
  toolSlug: 'google_drive_upload',
  toolkitSlug: 'google_drive'
});
```
