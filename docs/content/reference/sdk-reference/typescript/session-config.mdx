## Returned config

```typescript
import type { ToolRouterSessionConfig } from '@composio/core';
```

`ToolRouterSessionConfig` resolves the installed client definition `SessionCreateResponse.Config`. It is not the create or PATCH input. The API uses snake_case names here, stores normalized account arrays, and returns sandbox settings under `workbench`.

### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `user_id` | `string` | Yes | User identifier for this session |
| `toolkits` | `undefined` \| [`toolkits.variant.2`](session-config#returned-config-toolkits-variant-2) \| [`toolkits.variant.3`](session-config#returned-config-toolkits-variant-3) \| [`toolkits.variant.4`](session-config#returned-config-toolkits-variant-4) | No | Toolkit configuration - either enabled list or disabled list, or toolkits whose tools need approval |

| `instant` | `false` \| [`instant.variant.2`](session-config#returned-config-instant-variant-2) | Yes | Instant usage settings. False disables instant usage; an object permits it subject to project permission and session toolkit and tool restrictions. |

| `workbench` | `undefined` \| [`workbench.variant.2`](session-config#returned-config-workbench-variant-2) | No | Workbench configuration |

| `proxy_execute` | `undefined` \| [`proxy.execute.variant.2`](session-config#returned-config-proxy-execute-variant-2) | No | Proxy execute configuration for this session. Omitted when not set. |

| `connected_accounts` | `undefined` \| Record&lt;`string`, Array&lt;`string`&gt;&gt; | No | Per-toolkit connected account overrides (array of nano-IDs). Multi-account sessions can pin more than one account per toolkit; otherwise length is 1. |
| `search` | [`search`](session-config#returned-config-search) | Yes | Search helper configuration |
| `execute` | [`execute`](session-config#returned-config-execute) | Yes | Execute helper configuration |
