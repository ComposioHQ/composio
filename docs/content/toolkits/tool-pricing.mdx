---
title: Tool pricing
description: Understand charges for Instant Tools and other tool calls
---

Most tool calls count toward your plan's tool-call allowance. Some tools can also incur a premium usage charge when they run on a Composio-hosted account. This is a charge for the specific tool call, not a separate class of "premium toolkits." A toolkit can contain both eligible and ineligible tools.

For Instant Tools, Composio provides a hosted account so an eligible tool can run without an end-user provider connection. Other tools in the same toolkit may still require your user's account. See [Instant Tools](/docs/instant-tools) for Session configuration and account selection.

## Check the price

Check the tool's listed rate and unit before enabling premium usage. The amount may depend on usage, such as the number of results, characters, or minutes. See the [current pricing page](https://composio.dev/pricing) for rates and your plan's included usage. An eligible tool call charges your organization's balance; normal platform tool-call pricing can also apply.

## Check limits

Tool execution remains subject to your plan's API limits. See [Rate Limits](/reference/rate-limits) for current limits. If you need more, [contact us](https://composio.dev/contact?utm_source=docs&cta_placement=docs-pro-tools).
