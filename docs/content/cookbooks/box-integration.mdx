## Composio Box Integration

Composio's Box integration lets you connect AI agents to Box — read, write, upload, download, search, and manage files and folders without building an auth layer from scratch.

## How to Connect Box

1. Go to [app.composio.dev](https://app.composio.dev)
2. Search for **Box** in the integrations list
3. Click **Connect** and sign in with your Box account
4. Authorize the requested permissions
5. Done — your Box account is now available to any agent or workflow in Composio

## What You Can Do

- Read and download files and folders
- Upload and create new files
- Search across your Box content
- Move, copy, rename, and delete files
- Manage folder structures and permissions
- Chain Box actions with 1000+ other tools (Slack, Gmail, Notion, GitHub, and more)
