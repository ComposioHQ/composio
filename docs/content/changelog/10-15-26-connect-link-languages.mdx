---
title: "Show the Connect Link in Spanish or Simplified Chinese"
description: "Add a locale parameter to the Connect Link URL to show the hosted connection page in your user's language."
date: "2026-10-23"
---

The Connect Link can now show its text in Spanish or Simplified Chinese. Add a `locale` parameter to the Connect Link URL, such as `?locale=es` or `?locale=zh-CN`, so the page matches the language of your app.

### What's new

- **Choose the language per user.** Append `locale` to the `redirect_url` returned by `session.authorize()` or `connected_accounts.link()` before you send it to the user. Links without the parameter show English, as before.
- **The whole flow stays in one language.** The connect screen and the success or failure screen after the OAuth provider sends the user back all use the language you chose.
- **Other values show English.** The Connect Link accepts `en`, `es`, and `zh-CN` exactly as written. Any other value, including `es-MX`, shows English.

Field names and help text on API key forms, error details from the provider, and the provider's own sign-in and consent screens keep their original language. See [White-labeling authentication → Language](/docs/authentication/white-labeling-authentication#language) for examples in Python and TypeScript.
