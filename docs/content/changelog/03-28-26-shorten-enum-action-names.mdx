---
title: "Shorter Action Enum Names"
description: "82 action enum values renamed to comply with 60-character limit for better readability and consistency"
date: "2026-03-28"
---

We've shortened 82 action enum names across 16 toolkits to comply with the 60-character `MAX_ENUM_LENGTH` limit. The verbose, sentence-like identifiers have been replaced with concise, descriptive names while preserving the same underlying functionality.

<Callout type="warn">
**Breaking Change**

If your code, workflows, or agent configurations reference any of the old enum values, you must update them to the new values. The actions themselves — parameters, responses, and behavior — are unchanged.
</Callout>

### Why This Matters

- Enum values are derived from class names using `{APP_NAME}_{underscore(className).upper()}`
- Some class names were full English sentences (e.g., `ReturnsAListOfUsersWhoHaveFavoritedOrLikedTheTrack` at 72 chars)
- The lint check enforces a 60-character max to keep enum identifiers manageable for both developers and AI agents
- Shorter enums reduce token usage and improve tool selection accuracy in agent workflows

### Example

**Before:**
```
SOUNDCLOUD_RETURNS_A_LIST_OF_USERS_WHO_HAVE_FAVORITED_OR_LIKED_THE_TRACK  (72 chars)
```

**After:**
```
SOUNDCLOUD_GET_TRACK_LIKERS  (27 chars)
```
