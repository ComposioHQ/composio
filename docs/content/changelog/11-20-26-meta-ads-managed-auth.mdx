The Meta Ads toolkit (`metaads`) now supports Composio managed auth. You can connect users to Meta Ads with Composio-managed OAuth instead of creating and maintaining your own Meta OAuth app and auth config.

### What's new

- **Composio managed OAuth for Meta Ads.** Composio provides the OAuth app for the `metaads` toolkit, so there is no auth config of your own to set up before connecting an account.
- **Bring your own auth still works.** The toolkit continues to support OAuth2 and API key auth with your own credentials if you want your own app or need control over what it requests.

### Getting started

See the [Meta Ads toolkit page](/toolkits/metaads) for the full list of tools and authentication details.
