---
title: "Enhanced Security Masking for Sensitive Fields"
description: "Sensitive fields now show first 4 characters instead of full REDACTED"
date: "2025-12-10"
---

We've improved the security masking for `REDACTED` fields in the following APIs:

- [Get Connected Account](https://docs.composio.dev/rest-api/connected-accounts/get-connected-accounts-by-nanoid)
- [List Connected Accounts](https://docs.composio.dev/rest-api/connected-accounts/get-connected-accounts)

**What's Changed:**
Sensitive fields are now partially masked, revealing only the **first 4 characters** to help with debugging while maintaining security.

**Example:**
```
Before: REDACTED
After:  abcd...
```

### Current behavior

Connected-account OAuth tokens are now redacted for both Composio-managed and custom auth configs. Project masking settings do not restore raw access tokens, refresh tokens, or authorization headers in connected account responses.

Use [Proxy execute](/docs/extending-sessions/proxy-execute) when you need to call a provider API without handling its raw credentials. See the [June 4 security update](/docs/changelog/2026/06/04) for details.
