Python SDK `composio` `2.0.0b0` replaces the frozen `composio-client` dependency with the Composio-owned `2.0.0rc6` client.

Install the beta with:

```bash
pip install composio==2.0.0b0
```

To use the beta with a provider, install both explicitly:

```bash
pip install composio==2.0.0b0 composio-openai
```

### SDK versions

| SDK               | Version   |
| ----------------- | --------- |
| Python `composio` | `2.0.0b0` |

The Python provider packages remain on their stable `0.x` release train. Their existing `composio` dependency lets an explicitly installed `composio==2.0.0b0` supply the shared SDK runtime.

### Owned client

The owned client covers the released v3.1 operations while preserving the SDK's existing imports, types, retries, timeouts, and error classes.

This beta contains no additional SDK behavior changes beyond the client migration. No call-site migration is required when upgrading from `0.20.0`.
