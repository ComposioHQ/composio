---
title: "Scoped API Keys: Tools Read Operations Now Accept Read-Scoped Keys"
description: "Fixed a bug where reading tools required a write-scoped API key instead of a read-scoped one"
date: "2026-09-21"
---

Tools read operations were incorrectly gated behind the write API key scope. Read-scoped API keys can now fetch and list tools as expected.

### Bug Fixes

- Tools read endpoints (fetching and listing tools) previously required a write-scoped API key. They are now correctly scoped as read operations, so read-scoped API keys work without needing write permissions.

### Backward Compatibility

This is a bug fix with no breaking changes. If you were already using a write-scoped key, nothing changes. If you have a read-scoped key, you can now use it to read tools.
