Use these routes when a request is not primarily a support or debugging issue.

## Hiring

Direct hiring inquiries to Composio's public careers channel.

## DPA, enterprise data handling, and compliance

Pro and Enterprise Developer customers can accept the [standard DPA](https://composio.dev/legal/dpa) in Organization Settings > Billing > Data Processing Addendum. Route requests for bespoke data-processing terms or end-to-end contractual no-training requirements to the Enterprise track. See [Compliance, Data Retention, and Model Training](/kb/guide/platform-compliance-data-handling) for details.

## Tool or toolkit feature requests

Submit requests through the [Composio request board](https://request.composio.dev).
