This example puts an agent in Slack, where a whole team can talk to it, and wires it so the agent can actually *do* things like open a PR, check a calendar, or search a Notion workspace, on behalf of whoever is typing.

The agent is [Pi](https://github.com/earendil-works/pi-coding-agent), but the agent is the easy part. The work is the four Composio pieces that turn "an agent in a terminal" into "an agent in your workspace":

1. **Triggers** deliver every Slack message to your server as a webhook.
2. **Sessions** give each user their own scoped toolset, so the agent acts as *them*.
3. **A shared connection** lets the bot speak as the workspace bot, with one install for everyone.
4. **The proxy** reaches the Slack Web API endpoints the toolkit doesn't wrap as tools.

## Setup

You need a [Composio API key](https://dashboard.composio.dev), a publicly reachable URL for your server, and [Bun](https://bun.sh).

## Install the bot

A Slack bot needs a Slack app to authenticate as and a stream of events. Composio gives you both, so you never register a webhook with Slack or hold a bot token. The `slackbot` toolkit ships with Composio-managed OAuth, and you install it as one **[shared connection](/docs/authenticating-users/shared-connections)** for the whole workspace.

## Build the bot

Now the server. The key move is that **each Slack user gets their own [session](/docs/configuring-sessions)**: when Alice asks the bot to open a GitHub issue, it opens as *Alice*, against her GitHub connection. The session also pins the one shared Slack connection, so the agent posts as the workspace bot while acting in every other app as the user. Slack actions the toolkit doesn't wrap, like the typing indicator, drop down to the **proxy**, which calls the Slack Web API with the pinned connection's auth so you never touch a token.

## Run it

Run `bun install.ts` once to set up the bot, start the server with `bun bot.ts`, then `@mention` the bot in any channel. It opens a session as you, finds the tool it needs, runs it against your connections, and replies in thread as the workspace bot, usually within a few seconds.
