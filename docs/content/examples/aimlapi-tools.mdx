---
title: Use AI/ML API with Composio tools
description: Run Composio tools with any AI/ML API chat model through the OpenAI-compatible API
---

This example shows how to use Composio tools with an AI/ML API chat model. AI/ML API exposes an OpenAI-compatible API, so you can keep Composio's OpenAI tool format and point the OpenAI SDK at `https://api.aimlapi.com/v1`.

## What you'll build

- A small TypeScript script that asks a model to look up a Hacker News user
- Composio tool definitions in OpenAI function-calling format
- Tool execution handled by Composio, with the final answer generated by AI/ML API

## Prerequisites

- Node.js 18+
- [Composio API key](https://dashboard.composio.dev/settings)
- [AI/ML API key](https://aimlapi.com/app/keys)
- An AI/ML API chat model ID from [the model catalog](https://aimlapi.com/models)

## Project setup

Create a project and install the dependencies:

```bash
mkdir composio-aimlapi-tools && cd composio-aimlapi-tools
npm init -y
npm install @composio/core @composio/openai openai dotenv
npm install -D tsx typescript
```

Add your keys and model to `.env`:

```bash title=".env"
COMPOSIO_API_KEY=your_composio_api_key
AIMLAPI_API_KEY=your_aimlapi_api_key
AIMLAPI_MODEL=openai/gpt-4o-mini
```

## Create the agent script

Create `index.ts`:

```ts title="index.ts"
import 'dotenv/config';
import { Composio } from '@composio/core';
import { OpenAIProvider } from '@composio/openai';
import OpenAI from 'openai';
import type { ChatCompletionMessageParam } from 'openai/resources/chat/completions';

const userId = 'default';
const model = process.env.AIMLAPI_MODEL ?? 'openai/gpt-4o-mini';

const openai = new OpenAI({
  apiKey: process.env.AIMLAPI_API_KEY,
  baseURL: 'https://api.aimlapi.com/v1',
});

const composio = new Composio({
  apiKey: process.env.COMPOSIO_API_KEY,
  provider: new OpenAIProvider(),
});

const tools = await composio.tools.get(userId, 'HACKERNEWS_GET_USER');

const messages: ChatCompletionMessageParam[] = [
  {
    role: 'system',
    content: 'You are a helpful assistant. Use tools when they help answer the user.',
  },
  {
    role: 'user',
    content: "Find information about the Hacker News user 'pg'.",
  },
];

const firstResponse = await openai.chat.completions.create({
  model,
  messages,
  tools,
  tool_choice: 'auto',
});

const toolMessages = await composio.provider.handleToolCalls(userId, firstResponse);

if (toolMessages.length === 0) {
  console.log(firstResponse.choices[0]?.message.content);
  process.exit(0);
}

const finalResponse = await openai.chat.completions.create({
  model,
  messages: [...messages, firstResponse.choices[0].message, ...toolMessages],
});

console.log(finalResponse.choices[0]?.message.content);
```

## Run it

Run the script:

```bash
npx tsx index.ts
```

The model receives the Hacker News tool schema from Composio. If it chooses to call the tool, Composio executes the tool call and sends the result back to the model for the final answer.

## How it works

`OpenAIProvider` formats Composio tools for OpenAI-compatible function calling. The only AI/ML API-specific part is the OpenAI SDK client:

```ts
import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: process.env.AIMLAPI_API_KEY,
  baseURL: 'https://api.aimlapi.com/v1',
});
```

You can switch models by changing `AIMLAPI_MODEL`. Keep using exact model IDs from the AI/ML API catalog.

## Use authenticated toolkits

The Hacker News tool works without OAuth. For authenticated toolkits such as Gmail, Slack, or GitHub, create or reuse a Composio session and connect the user's account first. The model client stays the same; Composio still manages toolkit authentication and tool execution.
