- **Python schema converter silent `except: pass`** (`python/composio/utils/schema_converter.py:242-245`): add a debug/warning log with the tool slug before falling back to permissive models. S effort; fold into any nearby Python PR.

## Findings considered and rejected

- **CLI bypasses `@composio/core`** (uses raw `@composio/client` + its own Effect model layer, ~36k lines): real and the largest debt in the repo, but a unification is a multi-week rewrite with HIGH regression risk one month before v1, and the CLI is private/unpublished so it gates nothing. Verdict: document the split as an ADR, bound drift via the existing parity guardrail, revisit after the Hey API client migration (docs/plans 001) which changes the substrate anyway.
- **OpenAI SDK as a hard dependency of both cores** (default provider): changing the zero-config default (`new Composio()` works without choosing a provider) IS a public-interface change — excluded by this run's constraint. Candidate for a lazy-import spike post-v1.
- **Alpha `@composio/client` pin, Python `Dict` returns, missing AsyncComposio, `initiate()` retirement, MCP/custom-tools experimental status**: all already settled and sequenced in `docs/decisions/` + `docs/plans/` — not re-reported.

- **`ts/packages/slim` as a copy of core dist**: intentional source-free publish variant with its own smoke test; not dead code.
