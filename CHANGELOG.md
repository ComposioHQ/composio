# Changelog

Composio release notes are published in the [official changelog](https://docs.composio.dev/reference/changelog).

If you're working from this repository and want to know what changed between versions, everything on that site is also here:

| What | Where in this repo |
| --- | --- |
| Per-release notes for `@composio/core` and the other TypeScript packages, including behavior changes | `ts/packages/<package>/CHANGELOG.md` (for example [`ts/packages/core/CHANGELOG.md`](ts/packages/core/CHANGELOG.md)) |
| Per-release notes for the Python SDK | [`python/CHANGELOG.md`](python/CHANGELOG.md) |
| Product and API changelog entries | [`docs/content/changelog/`](docs/content/changelog/) |
| Migration guides with before/after code | [`docs/content/docs/migration-guide/`](docs/content/docs/migration-guide/) ([published](https://docs.composio.dev/docs/migration-guide)) |

Before upgrading, read the package changelog for every version between yours and the target, and search it for "breaking" and "behavior change".
